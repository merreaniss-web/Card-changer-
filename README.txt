WALLET LAB — VERSION 2.0

CONTENU
- index.html : application complète, autonome, sans bibliothèque externe.
- manifest.webmanifest : configuration PWA.
- sw.js : cache hors-ligne après la première visite sur HTTPS.
- icon.svg : icône.

MISE EN LIGNE (GitHub Pages)
1. Décompressez cette archive.
2. Déposez directement index.html, manifest.webmanifest, sw.js et icon.svg à la racine du dépôt GitHub (pas dans un sous-dossier).
3. Dans Settings > Pages, choisissez Deploy from a branch, branche main, dossier /(root), puis Save.
4. Ouvrez l'adresse HTTPS fournie par GitHub Pages.

UTILISATION
Catalogue : sélectionner un thème. Studio : modifier les textes, couleurs, finition ou importer une image. Recto/verso : prévisualiser les deux faces. Export PNG : ouvrir le visuel en grand (sur iPhone, maintenir l'image appuyée pour l'enregistrer). Enregistrer : sauvegarder dans le navigateur. Mes créations : modifier, supprimer, exporter ou importer une sauvegarde JSON.

LIMITATION IMPORTANTE
Wallet Lab est un studio graphique. Il ne peut pas changer le design natif d'une carte bancaire de paiement déjà présente dans Apple Pay. Le design d'une vraie carte Apple Pay est contrôlé par la banque émettrice. Les visuels créés ici sont des concepts décoratifs non payants.
